# Pet Figure Transform Remotion Template

8秒の縦型ショート動画テンプレートです。

## Composition

- `PetFigureTransform`
- 1080 x 1920
- 30fps
- 240 frames

## Assets

画像は `public/assets/pet-adventurer/` に置いています。

- `source.png`: 元画像
- `modeling.png`: 3Dモデリングデータ風
- `figure.png`: 完成フィギュア風

## Commands

```bash
npm install
npm run studio
npm run still
npm run render
```

## Template Props

Remotion Studioの右側パネルから差し替えできます。

- `sourceImage`
- `modelingImage`
- `figureImage`
- `headline`
- `subline`
- `finalLabel`
